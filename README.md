# FlashCards AngularJS

This is a static AngularJS web app. To enable the web preview runner (which expects an install/start lifecycle), a minimal Node tooling setup is included.

## Run locally

1. Install Node.js (v16+ recommended)
2. Install dependencies:
   npm install
3. Start a static server:
   npm start

The server listens on PORT (if provided) or defaults to 3000. Open http://localhost:3000/index.html or http://localhost:3000/angindex.html.

No build step is required; this app is pure HTML/CSS/JS.
